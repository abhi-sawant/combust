# Combust Android

Native Kotlin app, same features/UI/backend as `web/`. Package `com.slowatcoding.combust`, minSdk 26.
Build with Android Studio's JDK: `export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"`, then
`./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug` (release: `:app:assembleRelease`).

- `:core` (pure Kotlin/JVM): port of `web/src/lib` (same function names), plus `LocalData` (port of `local-db.ts`) and
  `SyncEngine` (port of `sync.ts`) over a `RecordStore` interface. Tests replay `spec/fixtures` (generated by the web code)
  and simulate two-device sync.
- `:app`: Compose UI, Room (`RoomRecordStore`), OkHttp (`CombustApi`), `AppController` (plays web's Auth/Sync/Vehicles/Entries
  providers), WorkManager `SyncWorker`. Manual DI via `CombustApp.controller`; no ViewModels/Hilt.
- Design tokens: `ui/theme/Theme.kt` mirrors `web/src/index.css`. Never use raw hex or stock Material colours.
  Icons are generated from lucide-react (`ui/components/LucideIcons.kt`); fonts in `res/font`.
- Update check: `AppUpdate.kt` (pure, tested) + `update/UpdateChecker.kt` + `UpdateDialog`; once per app open, shows the
  GitHub release notes, "Skip this version" is remembered. The app does not install updates itself (sideloaded).
- Version comes from the root `VERSION` (`versionCode = major*10000 + minor*100 + patch`).
- API URL: `BuildConfig.API_URL` (default prod; `-PcombustApiUrl=...` to override).
- Signing: gitignored `android/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`), keystore in
  `android/keystore/`. Without it the release APK is unsigned. Always sign with the same key.

## PWA to Android mapping
| Web | Android |
|---|---|
| IndexedDB (`local-db.ts`) | Room via `RecordStore` + `LocalData` |
| localStorage keys | `Prefs` (SharedPreferences) |
| `use-auth/use-sync/use-vehicles/use-entries` | `AppController` |
| shadcn Sheet / AlertDialog / sonner | `EmberSheet` / `ConfirmDialog` / `ToastHost` |
| Recharts / `MileageBars` | Canvas `LineChart` / `MileageBars` |
| next-themes | `ThemeChoice` + `CombustTheme` |

Not yet ported (web-only): wide-screen table layouts (Android uses the mobile layouts everywhere).
