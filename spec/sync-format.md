# Data and sync contract

Both clients (web, Android) keep data locally and, when signed in, sync it with the backend through
`POST /sync`. Changing any persisted field means updating this file, the PHP backend
(`backend/src/Controllers/SyncController.php`), the web code and the Android code together.

## Records

All records carry sync metadata: `updatedAt` (epoch ms, last write wins), `deletedAt` (epoch ms or
`null`; a non-null value is a tombstone), and a local-only `dirty` flag that is **never sent**.
IDs are client-generated UUIDs (36 chars, hex and dashes).

Vehicle: `{ id, name, plate?, createdAt (ISO-8601 UTC), updatedAt, deletedAt }`

Entry: `{ id, vehicleId, date ("yyyy-MM-dd"), odometerReading, fuelStation, amountPaid,
litresFilled, isFullTank, missedPrevious, updatedAt, deletedAt }`

## `POST /sync` (Bearer JWT)

Request: `{ cursor: <epoch ms>, vehicles: [...], entries: [...] }` — at most 5000 records in total.
Response: `{ cursor: <server epoch ms>, vehicles: [...], entries: [...] }` including tombstones.

Server: upserts each record only if it is new or `incoming.updatedAt > stored.updatedAt`, then returns
every record of the user with `synced_at >= cursor` (inclusive on purpose; clients apply idempotently).
Invalid rows are skipped silently.

## Client rules

- **Stamps:** add → `updatedAt = now`. Update/delete → `max(now, previous.updatedAt + 1)`. Delete sets
  `deletedAt = updatedAt`. Deleting a vehicle tombstones the vehicle and its live entries with one stamp.
- **First sync with an account** (no cursor): mark everything dirty and use `cursor = 0`.
- **Apply remote:** overwrite a local record when it is missing or `remote.updatedAt > local.updatedAt`
  (store with `dirty = false`). After pushing, clear `dirty` only if `local.updatedAt` still equals the
  value sent, so edits made during the request stay dirty.
- **Linking:** if the device was linked to a different email, wipe local data before linking the new
  account. If it was never linked, keep local data and merge it into the account.
- **Sign out:** keep data, drop cursor and last-synced time.
- **Reads** hide tombstones; entries are ordered by `odometerReading`, vehicles by `createdAt`.
- Everything is also available offline: the app works fully in "local mode" without an account.

## Golden fixtures

`spec/fixtures/*.json` hold inputs and outputs of the shared calculation logic, generated by the web
code (`cd web && npm run gen:fixtures`, timezone Asia/Kolkata) and replayed by the Android `:core` tests.
